Collect · Organize · Rediscover

留下的不只是图片，
还有下一次创作的起点。

从一次生成到一个收藏，从一段 Prompt 到一张参考图。让创作的上下文跟着作品，随时找回、复制和继续使用。

01 / COLLECT

作品与 Prompt，一起收藏。

保存图片和视频，记录提示词、模型、笔记与参考素材。手工创作也可以放进 HumanArts，保留自己的创作注记。

02 / ORGANIZE

按时间浏览，按线索找回。

在 Timeline 或列表中浏览资料库，用标题、Prompt、模型和标签搜索。收藏、归档与评分，让值得重访的作品更容易找到。

03 / REDISCOVER

打开作品，找回创作过程。

在详情里查看媒体与参考素材，复制保存的 Prompt。资料保存在设备上，也可以选择开启 iCloud 同步。

LumaLog on Mac · Agent tools

你的创作资料库，
也是 Agent 的上下文。

在 Mac 的桌面资料库里整理媒体和 Prompt，再通过内置 MCP 服务，让 Agent 找到并使用已经保存的创作素材。

Connect your agents.

Mac 版内置 MCP 服务，可连接 Codex、Claude Code、Cursor 和 Claude Desktop。Agent 可以检索条目、读取 Prompt 与媒体、创建或更新记录，以及整理标签。

Agent↔MCP↔LumaLog

从“找出上次的参考图”到“把这次创作存入资料库”，让已有作品成为下一次创作的材料。Mac 端还可以收藏和管理 Skill。

MCP 为 Mac 端功能，服务在 LumaLog 运行时提供。iOS 版用于记录、整理和查看资料库，不提供 MCP 服务。
