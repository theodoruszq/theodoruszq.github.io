QuickTranslate 隐私政策

更新日期：2026-10-14

适用范围

本政策说明 QuickTranslate Mac 应用及这些产品页面的数据处理方式。应用无需独立用户账号，不包含广告或第三方分析 SDK，也不通过开发者运营的服务器收集翻译内容。

文字、图片与剪贴板

应用处理你输入、粘贴或通过“翻译剪贴板”提交的文字与图片。图片使用 Apple Vision 在本机识别；当前翻译请求发送识别后的文字，不上传原始图片。App Store 版本不使用辅助功能权限读取其他应用的选中文字。

苹果翻译

选择苹果翻译时，文本通过 Apple Translation 系统框架处理。下载所需语言包后可在设备上离线翻译；首次使用或新增语言时，系统可能联网下载资源。Apple 系统服务的数据处理受 Apple 自身隐私政策约束。

第三方 AI 与自定义接口

选择第三方服务时，待翻译文本、自定义提示词、模型及相关请求参数会发送到你配置的接口，API Key 用于请求认证。接口服务会接收连接所需的网络信息，其保存期限、训练使用与数据处理规则由服务商决定。使用本地兼容接口时，请求发送到你配置的本地服务。请核对接口地址，并选择符合你隐私需求的服务。

本地保存

语言、快捷键、外观、服务配置和提示词等设置保存在本机。API Key 当前保存在应用支持目录下的本地 JSON 文件中，应用限制文件访问权限，但不另行加密，也不保证由系统钥匙串保存。翻译结果缓存保存在进程内存中，不作为持久翻译历史写入磁盘；应用没有内置云端同步。系统备份或你配置的同步软件可能包含本地设置与凭据文件。

复制与控制

你主动复制译文，或启用“自动复制译文”时，结果会写入系统剪贴板，其他有剪贴板访问能力的应用可能读取它。可以关闭自动复制、清空输入，并在服务设置中清空不再使用的 API Key。退出应用会释放内存中的翻译缓存。卸载应用不保证删除所有设置、备份或外部副本；第三方已接收的数据需按其政策另行管理。

产品网页与支持邮件

这些产品页面没有外部脚本、分析工具、广告或浏览器本地存储，页面文件由 GitHub Pages 提供；托管服务可能处理访问请求中的 IP 地址和浏览器网络信息。你主动发送的支持邮件、邮箱地址及附件用于回复与排查问题，并由邮箱服务商按其政策处理。应用不会自动发送邮件或附件。隐私问题及支持邮件删除请求请联系 theodoruszq@gmail.com。

政策更新

数据处理方式变化时，我们会更新本页面及更新日期。

QuickTranslate Privacy Policy

Updated: October 14, 2026

Scope

This policy describes data handling in the QuickTranslate Mac app and these product pages. The app requires no separate user account, contains no advertising or third-party analytics SDK, and does not collect translation content through developer-operated servers.

Text, images, and the clipboard

The app processes text and images you type, paste, or submit with Translate Clipboard. Apple Vision recognizes image text on your Mac. Current translation requests send recognized text, not the original image. The App Store version does not use Accessibility permission to read text selected in other apps.

Apple Translation

When selected, Apple Translation processes text through the system framework. Translation can run offline on your device after the required language packs are downloaded. Initial setup or new languages may require system resource downloads. Apple system services are subject to Apple’s own privacy policy.

Third-party AI and custom endpoints

For third-party providers, text, custom prompts, model selection, and relevant request parameters are sent to your configured endpoint; API keys authenticate requests. Providers also receive network information needed for the connection. Retention, training use, and other handling depend on their policies. A local compatible endpoint receives requests through your configured local service. Check endpoint addresses and choose a service that meets your privacy needs.

Local storage

Language, shortcut, appearance, provider, and prompt preferences stay on your Mac. API keys are currently stored in a local JSON file in the application support directory with restricted file permissions. The app does not add encryption or guarantee storage in the system Keychain. Translation results are cached in process memory, not written as a persistent translation history. The app has no built-in cloud synchronization. System backups or synchronization tools you configure may include local preferences and credential files.

Copying and control

Copying a translation, or enabling automatic copying, places the result on the system clipboard, where other apps with clipboard access may read it. Disable automatic copying, clear input, and clear unused API keys in provider settings as needed. Quitting the app releases the in-memory translation cache. Uninstalling does not guarantee removal of all preferences, backups, or external copies. Manage data already received by providers under their policies.

Product pages and support email

These product pages contain no external scripts, analytics, advertising, or browser local storage. GitHub Pages serves the files and may process IP addresses and browser network information in access requests. Support emails, your email address, and attachments you choose to send are used to respond and troubleshoot, and are handled by email service providers under their policies. The app does not automatically send emails or attachments. Contact theodoruszq@gmail.com for privacy questions or requests to delete personal information from support correspondence.

Updates

We will update this page and its date when data handling changes.
