开始使用

首次打开后，前往设置选择翻译服务。使用“苹果翻译”无需填写 API Key；使用第三方服务时，填写对应的接口地址、模型与 API Key，并使用设置中的连接测试检查配置。

如何翻译文字或图片？

输入或粘贴文字到翻译窗口即可。图片请先复制，再粘贴到窗口，或在菜单栏选择“翻译剪贴板”。应用先识别图片中的文字，再进行翻译；请一次处理一张清晰图片。

苹果翻译提示缺少语言包？

按系统提示下载所需语言资源，下载时需要联网。确认源语言与目标语言受系统支持；语言资源准备完成后再重试。

AI 服务无法连接或返回错误？

检查接口地址、接口格式、模型名称和 API Key。Azure 格式的模型字段需要填写 deployment 名称；部分服务需要使用已开通的模型或接入点。确认网络正常、账号额度充足，并查看服务商返回的错误信息。

翻译方向不符合预期？

检查设置中的母语与目标语言。自动模式会将母语内容译为目标语言，其他内容译回母语；也可手动切换方向。自定义提示词应使用 {{target_language}} 表示本次实际输出语言。

快捷键无法使用？

在设置中重新录制一个未被其他应用占用的全局快捷键。App Store 版本通过输入、粘贴或菜单栏读取剪贴板，不提供自动读取其他应用选中文字的功能。

图片识别不完整？

使用清晰、尺寸合适的截图，减少复杂背景或分区域复制。单张图片不得超过 50 MB 或 8000 万像素。图片菜单中的“原始识别文本”可用于核对 OCR 结果。

Getting started

Open Settings and choose a provider. Apple Translation needs no API key. For a third-party provider, configure the endpoint, model, and API key, then use the connection test in Settings.

How do I translate text or images?

Type or paste text into the translation window. Copy an image, then paste it into the window or choose Translate Clipboard from the menu bar. Text is recognized before translation. Process one clear image at a time.

Apple Translation needs language packs?

Follow the system prompt to download the required language resources. Downloads need internet access. Check that your source and target languages are supported, wait for resources to be ready, and retry.

An AI provider fails to connect?

Check your endpoint, API format, model name, and API key. Azure-style endpoints use a deployment name in the model field. Some providers require an enabled model or inference endpoint. Check your network, account credit, and the error returned by your provider.

The translation direction looks wrong?

Check your native and target languages in Settings. Automatic mode translates native-language input into your target language and other input back into your native language. Switch direction manually when needed. Use {{target_language}} in custom prompts for the actual output language.

The shortcut does not work?

Record a global shortcut that is not already used by another app. The App Store version uses typed input, pasting, or clipboard translation; it does not automatically read text selected in other apps.

Image recognition misses text?

Use a clear screenshot with a simple background, or copy smaller regions. A single image must not exceed 50 MB or 80 million pixels. Open Recognized Text in the image menu to inspect the OCR result.
